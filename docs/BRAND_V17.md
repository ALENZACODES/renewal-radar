# V17 Brand Direction

The final user request shifted the visual reference from Canada.ca to Penn
Engineering. The app uses an original navy/crimson academic-financial identity,
restrained wave bands and a bespoke financial-navigation monogram. It does not
copy a university seal or claim affiliation or government endorsement.

The final transparent PNG was created with the built-in image generation tool,
then copied into frontend/assets/renewal-radar-naval-v17.png. Earlier ship/radar
drafts were rejected and are not referenced in this release. The large navy R
has a quiet hull/wave base and a rising brass radar/savings sweep ending at a
crimson contact. Its simplified silhouette remains readable as a small brand mark.

The final production prompt requested a premium original R monogram whose bowl
is a precision radar arc, whose diagonal suggests a savings trajectory, and whose
negative space suggests a vessel bow, with one wave below. It specified solid
navy #011F5B, minimal brass #A08B59 and crimson #990000 details, transparent
background, crisp geometry, small-size legibility, no badge, full radar grid,
literal battleship, money clipart, university seal, shadows or mockup.

Inter 4.1 is bundled from its verified GitHub release. Noto Sans remains the
locally bundled body font, and Lato is retained for the Canada-inspired base.
Georgia/system serif provides the brand lettering. Penn's proprietary TWK Everett
is not included. The interface is an operational mortgage workbench, not a clone
of Penn's marketing page. Charts retain meaningful labels, honest axes, source
dates, accessible data and distinct colours rather than imitating decorative data.
